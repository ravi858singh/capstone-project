Statistical audit agent

Does Model A really beat Model B?

A tool-using workflow that audits a claimed 3-percentage-point benchmark improvement, traces its decisions, and generates an evidence-based memo.
Prototype disclosure: this is a deterministic, rule-based agent workflow (not connected to an external LLM). The synthetic dataset and statistics are reproducible. It demonstrates orchestration, tool use, validation, intervention, and verification.

Proposed intervention plan

  1. State explicitly that example IDs match the same examples across models.
  2. Require paired analysis on per-example score differences and a 95% confidence interval.
  3. Count incomplete/dropped rows; stop on malformed schemas or duplicate IDs.
  4. Produce a per-category breakdown and flag categories where Model B wins.
  5. Generate every memo number directly from computed analysis output.
  6. Pause for plan approval before executing tools.

Current task brief

Instructions define what the agent checks and what it must verify.

GOAL Decide whether Model A improves benchmark accuracy by 3 percentage points over Model B. CONTEXT CSV columns: example_id, category, score_a, score_b. Scores are binary (0 or 1). CONSTRAINTS Produce an analysis and concise memo. Use available scores. ACCEPTANCE CRITERIA Compare overall accuracy and report a verdict. STOP CONDITIONS Stop if the file cannot be read.

What this project tests

Whether the agent infers the correct paired design from context.
Whether missing values remain visible in the audit trail.
Whether subgroup evidence changes the headline interpretation.
Whether memo claims trace back to programmatic output.
Defense tip: identify the first incorrect decision, the evidence that exposed it, and the exact instruction changed.
